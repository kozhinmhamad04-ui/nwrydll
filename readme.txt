نوری دڵ - ماڵپەڕی ستاتیک (HTML)

فایلەکان:
  index.html          لاپەڕەی سەرەکی
  prayer.html         نوێژ
  wudu.html           دەستنوێژ گرتن (بە وێنە)
  prayer-types.html   جۆرەکانی نوێژ
  dua.html            دوعا و زیکر
  zakat.html          زەکات
  topics.html         بابەتەکان
  society.html        ژیان و کۆمەڵگا
  books.html          کتێبەکان
  images/qr-links.png وێنەی QR کۆد

چۆن بیخەیتە سەر هۆست:
  1. هەموو فایلەکان و فۆڵدەری images بخەرە ناو فۆڵدەری public_html (یان www / htdocs)ـی هۆستەکەت.
  2. دڵنیابە index.html لە ڕیشەی فۆڵدەرەکەدایە.
  3. دۆمەینەکەت بە DNS ئاماژە بکە بۆ هۆستەکە (A record بۆ IPی هۆست، یان ناوی nameserverی هۆست).
  4. HTTPS (SSL) لە پانێلی هۆستەکەت چالاک بکە.

تێبینی: فۆنتەکان لە Google Fonts دێن و پێویستی بە ئینتەرنێت هەیە.
هیچ سێرڤەرێک یان داتابەیس پێویست نییە.
